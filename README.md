# ✨ GitHub Battle Arena

An arcade-styled battle arena where two GitHub users face off by comparing their contribution graphs in a visually exciting, game-like interface.

## 🚀 Features

- **User Selection** - Enter two GitHub usernames to begin the battle
- **Contribution Graphs** - Side-by-side visualization of contribution heatmaps
- **Battle Statistics** - Compare total contributions, streaks, and best days
- **Winner Declaration** - Automatic winner determination with celebratory animations
- **Responsive Design** - Optimized for mobile, tablet, and desktop
- **Arcade Aesthetics** - Bold colors, dynamic animations, and game-inspired UI

## 🛠️ Development

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```

### Linting
```bash
npm run lint
```

## 🧪 Testing

This project includes comprehensive E2E tests with Cypress covering all major features.

### Run Tests (Interactive Mode)
```bash
npm run cypress
# or
npm run test:e2e:open
```

### Run Tests (Headless Mode)
```bash
npm run cypress:headless
# or
npm run test:e2e
```
